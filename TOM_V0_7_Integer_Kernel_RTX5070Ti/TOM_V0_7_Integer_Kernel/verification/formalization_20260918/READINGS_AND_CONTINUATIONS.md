# Reading examples — not a simulation

## Example A: an unchanged source identity, without erasing the sheet

Compare the two defining expressions `Arch<c; -c>` and `Arch<c; -2c>` in an
explicit real-scalar interpretation. For nonzero c their second roles differ,
but each selected Arch reading is zero. The zero identity is kept exactly.
Inverse Occam prevents using it alone to delete the difference in the definitions.
The labels are editorial names, not continuum nodes.

## Example B: precedence produces genuinely different results

For the same declared scalar diagnostic, `arch(1, arch(2,3)) = 2` while
`arch(arch(1,2), 3) = 4`. Therefore a flattening transformation needs a proved law;
ordinary union-style reassociation is not licensed just by calling it Arch U.
This is a property of the printed formula, not a new physical theory.

## Example C: inversion does not pay for reverse time

A later interpretation may mirror a structural reading and still have to satisfy
TC1–TC5. A negative echo value does not authorize use of a future observation.
Similarly, a description of a long delay may be compact while that declared delay
remains causally prior to its later effect. The intrinsic definition does not
choose numeric units or a digital event queue to enforce that statement.

## Example D: a permitted future extension

A proposal that specifies a new jitter law can be reviewed for source roles,
SDF closure, preserved binding and the temporal clauses. Its chosen observations
must be stated. It does not become intrinsic TOM merely because it runs in a GPU
or produces a zero balance. The present release does not prescribe that new law.

## Example E: an actual regression caught by the contract linter

Changing `external_metric_required` to true replaces the core with a different
formal commitment. It is flagged. That does not forbid a separately named metric
interpretation; it prevents such an interpretation being smuggled into the
intrinsic definition. The same distinction applies to a graph, vector layout,
renderer or finite-state machine.
